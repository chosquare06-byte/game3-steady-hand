# Game 3: Steady Hand Test

A 3D first-person web game made with Three.js, Vite and Blender.

## Run
npm install
npm run dev

## Controls
- Start button: begin
- Mouse and WASD: look and walk
- E: play at the table or step back
- Mouse: move the ring (W/S or scroll for depth)
- R: restart
- Esc: free the mouse

## Goal
Guide the ring to the end without touching the wire.
